# UC-02 — Gerenciar biblioteca

## Ator

Usuário.

## Descrição

Permite que o usuário cadastre, visualize, edite, remova e organize os livros presentes em sua biblioteca.

## Fluxo principal

1. O usuário acessa sua biblioteca.
2. O sistema apresenta os livros cadastrados.
3. Os livros em leitura são apresentados com prioridade.
4. O usuário pode selecionar um livro para visualizar seus detalhes.
5. O usuário pode adicionar, editar ou remover livros.
6. O usuário pode classificar os livros como **Quero ler**, **Lendo** ou **Lido**.
7. O sistema salva as alterações realizadas.

## Fluxos alternativos

* Caso não existam livros cadastrados, o sistema apresenta a biblioteca vazia.
* Caso o usuário tente cadastrar um livro sem título, o sistema impede o cadastro.
* O usuário pode filtrar a biblioteca para visualizar apenas livros **Lendo**, **Quero ler** ou **Lidos**.
* Caso o usuário cancele uma edição ou exclusão, nenhuma alteração é realizada.
