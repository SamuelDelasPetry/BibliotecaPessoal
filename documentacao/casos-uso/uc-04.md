# UC-04 — Registrar leitura

## Ator

Usuário.

## Descrição

Permite que o usuário registre seu progresso durante a leitura de um livro, informando as páginas lidas e acompanhando o progresso total da obra.

## Fluxo principal

1. O usuário seleciona um livro de sua biblioteca.
2. O usuário escolhe a opção **Registrar leitura**.
3. O sistema apresenta os campos de página inicial e página final.
4. O usuário informa as páginas correspondentes à leitura realizada.
5. O usuário confirma o registro.
6. O sistema salva o registro de leitura.
7. O sistema atualiza a última página lida e calcula o percentual de progresso do livro.
8. Caso o livro esteja como **Quero ler**, seu estado é alterado para **Lendo**.

## Fluxos alternativos

* O usuário pode adicionar uma anotação ao registro de leitura.
* Caso a página final seja menor que a página inicial, o sistema impede o registro.
* Caso a página informada ultrapasse o total de páginas do livro, o sistema impede o registro.
* Caso o usuário cancele a operação, nenhum registro é criado.
