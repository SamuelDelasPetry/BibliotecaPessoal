# UC-01 — Gerenciar autenticação

## Ator

Usuário.

## Descrição

Permite que o usuário crie uma conta, realize login e encerre sua sessão no aplicativo.

## Fluxo principal

1. O usuário acessa a tela de autenticação.
2. O usuário informa seus dados.
3. O sistema valida as informações.
4. O sistema autentica o usuário.
5. O usuário é direcionado para sua biblioteca.

## Fluxos alternativos

* Caso o usuário ainda não possua uma conta, poderá acessar a opção de cadastro.
* Caso os dados informados sejam inválidos, o sistema informa o erro e não realiza o login.
* O usuário autenticado pode encerrar sua sessão utilizando a opção de logout.
