# UC-07 — Consultar livros lidos

## Ator

Usuário.

## Descrição

Permite que o usuário consulte os livros que já concluiu e visualize as informações registradas durante e após suas leituras.

## Fluxo principal

1. O usuário acessa sua biblioteca.
2. O usuário seleciona a visualização de livros **Lidos**.
3. O sistema apresenta os livros concluídos.
4. O usuário seleciona um livro.
5. O sistema apresenta os detalhes da obra.
6. O sistema exibe a nota, o comentário final e as informações da leitura.
7. O usuário pode consultar os registros e anotações relacionados ao livro.

## Fluxos alternativos

* Caso não existam livros concluídos, o sistema apresenta uma mensagem informativa.
* Caso o livro não possua anotações, a área correspondente é apresentada vazia.
