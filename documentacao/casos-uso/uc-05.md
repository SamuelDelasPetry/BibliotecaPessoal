# UC-05 — Gerenciar anotações

## Ator

Usuário.

## Descrição

Permite que o usuário registre e consulte anotações relacionadas às suas leituras.

## Fluxo principal

1. O usuário acessa um livro de sua biblioteca.
2. O usuário acessa as anotações da leitura.
3. O sistema apresenta as anotações existentes.
4. O usuário adiciona uma nova anotação.
5. O usuário informa o conteúdo da anotação e, opcionalmente, a página relacionada.
6. O sistema salva a anotação associada à leitura do livro.

## Fluxos alternativos

* O usuário pode adicionar uma anotação durante o registro de uma leitura.
* O usuário pode editar ou remover uma anotação existente.
* O usuário pode associar informações opcionais à anotação, como cor ou tópico.
* O usuário pode filtrar as anotações pelas informações disponíveis.
* Caso o usuário cancele a criação ou edição, nenhuma alteração é realizada.
