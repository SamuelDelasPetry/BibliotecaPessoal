# UC-03 — Gerenciar wishlist

## Ator

Usuário.

## Descrição

Permite que o usuário mantenha uma lista de livros que deseja adicionar futuramente à sua biblioteca.

## Fluxo principal

1. O usuário acessa a wishlist.
2. O sistema apresenta os livros adicionados à lista.
3. O usuário pode adicionar, editar ou remover livros.
4. O usuário seleciona um livro da wishlist.
5. O usuário escolhe a opção **Adicionar à biblioteca**.
6. O sistema remove o livro da wishlist.
7. O sistema adiciona o livro à biblioteca com o estado **Quero ler**.

## Fluxos alternativos

* Caso a wishlist esteja vazia, o sistema apresenta uma mensagem informativa.
* Caso o usuário tente adicionar um livro sem título, o sistema impede o cadastro.
* O usuário pode remover um livro da wishlist sem adicioná-lo à biblioteca.
* Caso uma operação seja cancelada, nenhuma alteração é realizada.
